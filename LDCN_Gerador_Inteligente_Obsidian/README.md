# Como usar esta pasta no Obsidian

1. Copie a pasta `LDCN_Gerador_Inteligente_Obsidian` para dentro do seu vault.
2. Abra `00 - Gerador Inteligente - Mapa Raiz`.
3. Navegue pelos links `[[...]]`.
4. O Graph View do Obsidian mostrará automaticamente as relações entre as camadas.
5. Não renomeie os arquivos sem atualizar os wikilinks.

O documento raiz é o índice canônico. Os demais documentos são módulos da mesma arquitetura.
